# SMS Squema

Interactive guide to the SMS database: its tables grouped by topic and explained in plain words, plus a full
technical reference of every table, column, field code, index and relationship.

It shows the database structure and SMS's own descriptions of it (RB_TABLES, RB_FIELDS, RB_JOINS); it contains no
store data.

This repository only hosts the published site. It is generated by the `sms-squema` project (SmsSquema.Exporter writes
`data/schema.json`) and served by GitHub Pages from the `main` branch.
